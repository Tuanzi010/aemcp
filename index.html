▸ 关于
AE MCP 桥是让 AI 客户端（Claude / Codex / Cursor 等）直接操控 After Effects 的桥接面板： 它把 MCP 协议里的自然语言指令翻译成 ExtendScript，在 AE 主线程里执行建合成、加图层、调属性、 加效果、打关键帧、上表达式、渲染导出等操作，并把工程状态与诊断信息读回给 AI。 面板必须保持打开（它在 CEP 的 Node 上下文里跑 MCP 服务，同时是唯一能进 AE 主线程的通道）。
可调用工具
合成、图层、属性、关键帧、表达式、效果、蒙版、标记、文本、形状路径、3D 相机灯光、 素材导入与代理、渲染队列、文本动画器、工程管理、颜色空间、MOGRT、查看器与设置、 模板与预设、检查点与批处理、能力探测与自检
